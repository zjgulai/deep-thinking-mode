自我效能感构建法★★★★★

自我效能感：不是'我能行'的口号，是'我做成过'的证据
📌 核心定义
个体对自己有能力组织并执行整套行动、以达成特定目标的内在信念。不是泛泛的'我能行'，而是'针对这件事，我曾经靠自己做成过'。
🔬 底层机制
班杜拉提出四大效能感来源：亲身成就经验（最强）、替代性经验、言语说服、生理情绪状态。核心闭环：自主设定微目标 → 对抗内在拉扯 → 完成可验证成果 → 大脑正向归因 → 固化掌控信念。关键：被动完成（被deadline推着）几乎不增长效能感；只有主动战胜内在阻碍的成功才有效。
🔔 识别信号
  • 面对任务第一反应是'我不行'
  • 能力足够但总觉得做不好
  • 被deadline推着走，完成也不觉得是自己的功劳
  • 需要外部认可才能确认自己不错
  • 换了领域就完全丧失信心
📋 操作步骤
  1. 设定最小可行挑战：难度略高于惰性、稍加克制就能完成
  2. 走完完整自主闭环：全程自我觉察——是我主动选择、是我控制行动、是我独立完成
  3. 完成后内心自我肯定：告诉'我战胜了惰性，掌控了自己的状态'
  4. 循序渐进拓宽领域：在一个领域建立稳定效能感后，迁移到新挑战
💡 示例
不想健身→先设定'穿上运动服'这个微目标→靠自主意志完成→内心确认'是我让自己动起来的'→下次设定'做5个俯卧撑'→逐级扩展

📌 核心定义

🔬 底层机制
* **本质**：这是一种指向过去、无法改变的懊悔性内省。它激活大脑的后扣带回皮层（与反刍思维相关），让人沉浸在已无法更改的情景中，容易引发自我责备或无力感。 * **结果**：思维被困在“过去时”的平行宇宙里，消耗大量心理能量却无建设性产出，形成“总结悖论”——越想从过去学习，越感到挫败与停滞。
