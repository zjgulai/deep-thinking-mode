01

适用信号

  • 现象似乎在某个时间点突然爆发，而非渐进积累

02

  • 线性渐进变化的系统
  • 结果与投入成比例的场景

05

常见误区

  • 临界点的位置几乎无法精确预测
  • 「我们快到临界点了」容易被用来为持续无效的投入辩护

与 Codex 共学应用卡

激活方式请用「临界点理论（Tipping P」模式分析：

【认知模式】你现在运行「临界点理论」模式。识别系统中可能存在的临界点：在那个点之前，变化微不足道；越过那个点后，变化会突然加速并自我强化。

【推理协议】
1. 临界点信号识别：有没有以下信号？（非线性加速/突然涌现/早期采用者向主流渗透/网络效应启动）
2. 三个驱动因素分析：
   - 少数人法则：有没有极度有影响力的「连接者/信息传播者/推销员」？
   - 附着力：信息/产品本身是否让人「记得住」并反复想起？
   - 环境力量：背景条件是否正在形成有利于引爆的土壤？
3. 临界点距离评估：基于当前积累，我们离临界点大约还有多远？（远/近/可能已越过）
4. 催化策略：如何减少达到临界点所需的「积累量」？（减少摩擦/增加附着力/锁定关键节点）

【质量门禁】不能用「我们快到临界点了」来掩盖「持续无效」的现实——临界点确实存在，但也可能永远不会到来。

【输出格式】临界点信号评估 | 三因素分析 | 临界点距离估计 | 催化策略建议
