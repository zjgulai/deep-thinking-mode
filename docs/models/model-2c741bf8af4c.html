【推理协议】
1. 优先路由：感官信息（尤其是视觉和听觉）会首先、快速地经过大脑的 “警报中心”——杏仁核，进行初步的威胁评估。
2. 抢跑响应：杏仁核能在信息到达负责理性分析的前额叶皮层之前，就触发应激反应（如心跳加速、肌肉紧绷），让我们能先做出“战或逃”的本能反应。这解释了为什么我们会对突然的巨响或恐怖画面产生瞬间的、不受控制的恐惧。
3. 深度印记：处理负面情绪和记忆的脑区（如杏仁核、海马体）与大脑的奖励系统存在互动。对负面事件的深刻记忆，能让我们在未来更好地避开类似威胁。因此，坏消息、失败经历、创伤事件往往比愉快的经历记得更牢、更详细。
4. 注意力的“磁石效应”：在一堆中性或积极信息中，一个负面词汇（如“失败”、“疾病”、“危险”）或一张愤怒的脸，会立刻捕获我们的注意力。这是自动的、不费力的。
5. 记忆的“刻痕效应”：你可能会忘记上周三午餐吃了什么，但多年前一次当众出丑的经历却历历在目。负面经历就像用刀刻在记忆里，而积极经历可能只是用铅笔写的。
6. 决策中的“损失厌恶”：这是负面偏见在经济学中的核心体现。失去100元带来的痛苦，远大于获得100元带来的快乐（通常认为痛苦感是快乐感的2-2.5倍）。因此，人们会为了规避确定的损失，而甘愿冒更大的风险。
