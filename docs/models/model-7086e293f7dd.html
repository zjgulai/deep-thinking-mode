【推理协议】
1. 这是第一步：允许自己意识到情绪的存在，并诚实地承认它。
2. 压制 是说：“你不该有这种感觉，快走开！” （否定情绪的存在）
3. 给予空间 是说：“我注意到我现在很愤怒/很悲伤/很焦虑。”（像一位冷静的观察者，只是指出事实）
4. 做法：停下来，深呼吸，在内心说：“哦，我这里有愤怒。” 仅仅这个动作，就能让情绪从“控制你”转变为“被你看见”。
