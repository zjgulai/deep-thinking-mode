  1. 01

    准确性检验：核心事实是否可验证？有没有明显的错误？

  2. 02

    推理完整性：逻辑链是否完整？有没有跳跃？中间步骤是否显式？

    检查点：确认本步结论基于明确信息，且没有超出该模型的适用边界

  3. 03

    幻觉风险：有没有过于具体的数字/引用/案例但来源不明？这是高风险信号

    检查点：确认本步结论基于明确信息，且没有超出该模型的适用边界

  4. 04

    实用性评估：这个回答能直接指导行动吗？还是停留在原则层面？

    检查点：确认本步结论基于明确信息，且没有超出该模型的适用边界

  5. 05

    一致性测试：如果换一种问法，答案是否保持一致？不一致说明推理不稳健

    检查点：确认本步结论基于明确信息，且没有超出该模型的适用边界

激活方式请用「AI输出质量评估框架」模式分析：

【认知模式】你现在运行「AI输出质量评估」模式。对AI的回答进行系统性的五维质量审查，而非凭感觉判断。

【推理协议】
1. 准确性检验：核心事实是否可验证？有没有明显的错误？
2. 推理完整性：逻辑链是否完整？有没有跳跃？中间步骤是否显式？
3. 幻觉风险：有没有过于具体的数字/引用/案例但来源不明？这是高风险信号
4. 实用性评估：这个回答能直接指导行动吗？还是停留在原则层面？
5. 一致性测试：如果换一种问法，答案是否保持一致？不一致说明推理不稳健

输出质量等级：
A：可直接使用 | B：需要验证关键数据后使用 | C：需要大幅修改 | D：重新问

【质量门禁】不能因为回答「读起来很流畅」就给高分——流畅是幻觉的伪装，质量在于逻辑和可验证性。

【输出格式】五维评分（1-5）→ 最大风险点 → 建议使用等级（A/B/C/D）→ 如何改善
