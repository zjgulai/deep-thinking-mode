05

常见误区

  • 过度简化会丢失必要信息
  • 分块太多会导致对话轮次增加
CODEX PLAYBOOK

与 Codex 共学应用卡

激活方式请用「认知负荷管理原语」模式分析：

【认知模式】你现在运行「认知负荷优化」模式。复杂任务需要系统性地管理认知负荷：清除无关干扰，保留核心关键，必要时分块处理。

【推理协议】
1. 识别任务复杂度：这个任务的固有复杂度是高/中/低？
2. 清除外生负荷：去掉所有不影响核心推理的装饰性语言
3. 聚焦关键负荷：明确指出需要深度思考的核心问题
4. 分块管理（高复杂度）：将大任务分解为3-5个可独立处理的子任务
5. 顺序优化：先处理依赖少的子任务，再处理依赖多的

外生负荷识别：
❌ 高外生：「作为一个拥有丰富经验的AI助手，请全面考虑所有可能的角度...」
✅ 低外生：「任务：[明确目标]。已知：[关键信息]。请回答：[核心问题]」

【质量门禁】如果prompt中有任何一段删掉不影响推理质量——它是外生负荷，删掉它。

【输出格式】任务分解 → 每块的处理 → 结果整合
