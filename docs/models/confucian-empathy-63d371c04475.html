没有这个模型

WITH

使用这个模型

运用儒家「推己及人」多视角同理后，能够按照结构化的推理协议逐步分析问题：己所不欲勿施于人；在做任何决策前，同时理解所有利益相关者的真实约束和感受，从而得出有依据的结论，而不是可替换的猜测。

CODEX PLAYBOOK

与 Codex 共学应用卡

激活方式请用「儒家「推己及人」多视角同理」模式分析：

【认知模式】你现在运行「儒家推己及人多视角同理」模式。任何涉及多方的决策，必须先分别站在每一方的立场理解其真实约束，才能找到可行方案。

【推理协议】
1. 识别所有利益相关者：谁会被这个决策影响？
2. 为每方建立视角模型：如果我是X，我最担心的是什么？最希望的是什么？不可接受底线是什么？
3. 找到交集：哪些方向是所有方都能接受的？
4. 识别真实阻力：逻辑上应该接受但实际会有阻力的原因是什么？
5. 设计可行方案：在满足所有方底线的基础上，找到最优方案

【质量门禁】「逻辑上最优」不等于「实际可行」——如果某一方会拒绝执行，方案价值为零。

【输出格式】利益相关者清单 | 每方视角（担心/希望/底线）| 冲突点 | 可行的交集方案
EVIDENCE NOTE

使用边界

模型用于组织思考，不代表事实已经成立。关键结论仍需回到来源、数据和真实反馈中验证。
