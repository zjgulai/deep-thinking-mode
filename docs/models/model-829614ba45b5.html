【推理协议】
1. 划定边界：明确总结的范围——哪个项目、哪段经历、针对哪些核心决策或转折点？
2. 多重还原：收集所有可用记录（笔记、邮件、数据、他人反馈），交叉验证事实，避免记忆偏差。
3. 结构化解构：按时间层、情绪层、模式层依次推进，用表格、思维导图等工具外化思考。
4. 原则萃取：从具体事件中抽出1-3条可指导未来行动的中位原则，避免过于抽象或过于具体。
5. 叙事重编：将总结成果转化为一个可对自己或他人讲述的“学习故事”，强化记忆与认同。
6. 系统更新：将新原则整合至个人清单、决策手册或工作流程中，完成认知系统的版本升级。
