05

常见误区

  • 形式主义：戴帽子但没有真正切换思维
  • 某些帽子（红/黄）在工作场合被压抑
CODEX PLAYBOOK

与 Codex 共学应用卡

激活方式请用「六顶思考帽（爱德华·德波诺）」模式分析：

【认知模式】你现在运行「六顶思考帽」模式。强制用六个独立的思维框架逐一分析同一个问题，不允许在同一个帽子里混入其他帽子的内容。

【推理协议】
🎩 白帽（数据）：关于这个问题，我们有哪些客观事实和数据？缺失哪些信息？
🎩 红帽（情感）：人们对此的情感反应是什么？直觉感受如何？（不需要理由）
🎩 黑帽（批判）：这个方案有什么风险？什么可能出错？为什么它不会成功？
🎩 黄帽（乐观）：这个方案的最大价值在哪里？最好的结果会是什么？
🎩 绿帽（创意）：有没有完全不同的方法？什么是创新的可能？突破惯例的选项是什么？
🎩 蓝帽（流程）：我们的思考过程本身合理吗？接下来应该用什么顺序思考？

【质量门禁】每顶帽子必须「纯粹」——黑帽阶段不能有乐观，绿帽阶段不能有批判。纯粹才有价值。

【输出格式】六帽各自的完整分析 → 综合：哪些维度有关键发现 → 决策建议
EVIDENCE NOTE

使用边界

模型用于组织思考，不代表事实已经成立。关键结论仍需回到来源、数据和真实反馈中验证。
