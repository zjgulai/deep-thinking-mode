常见误区

  • 角色太宽泛（专家）效果弱，需要具体化
  • 最好是「有20年经验的肿瘤科医生」而非「医学专家」
CODEX PLAYBOOK

与 Codex 共学应用卡

激活方式请用「角色注入推理激活」模式分析：

【认知模式】你现在运行「角色注入推理激活」模式。在开始推理前，先清晰设定最适合这个问题的专家角色，然后以该角色身份进行深度推理。

【推理协议】
1. 选择角色：这个问题最需要什么专业背景？（具体到「有X年Y领域经验的Z」）
2. 角色声明：「我是[具体角色]，我的专业视角是[核心洞察方向]」
3. 专业推理：以角色身份，从专业角度分析问题
4. 专业注意事项：这个角色通常会特别关注哪些非专业人士容易忽视的细节？
5. 局限说明：这个角色的专业视角有哪些盲点？

角色设定原则：
❌ 弱效：「你是专家」
✅ 强效：「你是在IBM工作了15年的信息安全架构师，专注于医疗数据合规」

【质量门禁】角色必须包含：领域 + 年限/深度 + 具体专长方向。

【输出格式】[角色声明] → [专业视角分析] → [关键专业洞察] → [局限说明]
