# 前车之鉴-思维制胜用户说明书

## 1. 适合解决什么问题

前车之鉴-思维制胜适合在问题复杂、信息分散或行动路径不清晰时，帮助你完成四件事：把问题说清楚、选择合适框架、按步骤推理、形成可验证行动。

它不是自动给出正确答案的 AI，也不是事实数据库。最好的使用方式是把它当成“推理工作台”：用结构降低遗漏，再用真实证据修正结论。

## 2. 三条常用路径

### 路径 A：我有一个具体问题

1. 进入“Agent 路由”。
2. 用一句完整的话描述目标、现状和困难，例如“项目连续延期，我想判断根因并制定下一步计划”。
3. 如果出现歧义，先回答页面唯一的澄清问题；第二轮仍不足时，改用八个意图快捷项，不继续无限追问。
4. 查看一个核心路径和最多两个辅助路径；优先核对“为什么这样匹配”和停止条件。
5. 当核心路由已策展 Chain 时，页面只激活这一条核心组合；辅助路径只补充模型和角色，不同时并行多条 Chain。

路由完全在浏览器内以确定性规则匹配，不会上传或保存输入，也不写入 URL、storage 或 cookie。它只能提供候选，不代表候选一定适用。

### 路径 B：我知道想用的模型

1. 进入“模型库”。
2. 输入名称、概念、触发信号或角色，例如“根因”“决策”“系统思维”。
3. 未输入关键词时按页浏览；搜索会检查完整模型库，结果较少时一次展示，结果较多时继续分页。
4. 打开详情页，先读“适用信号”和“不适用与停止条件”。
5. 按推理协议逐步执行，并在每个检查点停下来验证。

### 路径 C：我想系统学习

从首页的十三章认知地图进入。建议按“概览与工具箱 → 元认知与边界 → 问题定义 → 根因分析 → 决策与行动”的顺序建立基础，再根据工作场景跳转到其他章节。

### 路径 D：我想直接使用一条组合协议

1. 进入“组合工坊”，从五条已验证 Chain 中选择一条。
2. 先读适用、不适用与使用前输入，再按 1 到 N 的阶段顺序执行。
3. 每个阶段只把声明的输出交给下一阶段；检查点或停止条件命中时停下验证。
4. 需要与 Codex 协作时，复制详情页中由已验证阶段协议编排的复合 Prompt。

## 3. 一个完整的 Router 2.0 例子

假设输入：

> 项目连续延期，我想找出根因并制定下一步，完成后复盘。

当前规则会先进入 `clarify`，因为“找原因”、“做计划”和“做复盘”同时成为候选。选择“我想规划下一步”后，第二轮的实际路由结果是：

- 核心：计划设计，Agent 阶段为复盘反思。
- 辅助：诊断根因、复盘改进；只补充模型和角色。
- 唯一组合：`Plan–Execute–Reflect 执行闭环`。

接下来先打开核心模型，确认适用信号和停止条件；再进入该组合详情，按“目标与计划 → 执行 → 复盘”的真实阶段协议工作。这个例子说明的是规则结果，不是 AI 对问题的理解或最终判断。

## 4. 三种对象不要混淆

| 对象 | 回答的问题 | 有无顺序/交接/停止 | 如何进入 |
| --- | --- | --- | --- |
| 普通模型 | “这一个思考工具怎么用？” | 只有自身推理协议 | 模型库、章节或搜索 |
| 主题精选 | “这个场景有哪些模型值得看？” | 无；它是无序浏览集合 | 首页“主题精选” |
| 组合协议 | “多个模型如何依次交付并在失效时停止或回退？” | 有序阶段、输入输出、检查点、停止和可选回环 | 组合工坊、Router 或反向入口 |

主题精选不会因为放了多个模型就变成组合协议；普通模型被某条 Chain 引用时，其唯一主章节也不会改变。

## 5. 如何读一张模型卡

- **核心定义**：模型试图解决的认知任务。
- **适用信号**：什么时候值得调用它。
- **停止条件**：什么时候不应继续使用，避免套模型。
- **推理协议**：可执行步骤和每一步的检查点。
- **场景示例**：把抽象模型放进具体情境。
- **常见误区**：容易产生的滥用、偏差或失败模式。
- **Agent 角色**：模型在完整推理流程中承担的能力位置。
- **Codex 应用卡**：可复制的 activation 与 system prompt。

质量分用于内容治理和排序，不等同于事实可信度。关键判断要验证来源、时效和现实反馈。

## 6. 与 Codex 一起使用

当详情页出现“复制完整提示词”按钮时：

1. 复制提示词到 Codex。
2. 补充你的目标、约束、已有证据和期望输出。
3. 要求 Codex显式区分事实、假设、推断和待验证项。
4. 对高风险结论要求来源或独立复核。
5. 结论落地后记录反馈，再决定是否更新原判断。

不要把敏感信息直接写入不受信任的第三方服务。站点本身不联网，但你把提示词粘贴到其他产品后，应遵循该产品的数据政策。

## 7. 隐私、可访问性与离线边界

- 站点不加载远程字体、统计脚本或第三方资源。
- 搜索、筛选和路由在当前浏览器本地执行。
- 页面支持键盘导航、跳至正文、移动端布局、深色偏好、减少动效和打印样式。
- 这是多页站点；直接下载单个 HTML 不能构成完整离线副本。需要离线使用时应保存整个 `site/` 目录并通过本地 HTTP 服务打开。

## 8. 常见问题

**为什么搜索结果很多？**  
模型库包含不同来源和颗粒度的模型。先增加第二个关键词，或改用路由器缩小问题类型。

**为什么同名或相近模型会出现多次？**  
语料仍在持续去重和策展。优先参考定义、适用信号和推理协议，而不只看名称。

**路由没有匹配到结果怎么办？**  
补充目标和动词，例如“判断原因”“比较选择”“制定计划”；也可以直接在模型库搜索主题。

**复制按钮没有反应怎么办？**  
确认浏览器允许剪贴板访问；按钮仍会尝试使用本地兼容复制方式。也可手工选择提示词文本。

**能否用于医疗、法律或投资决策？**  
只能用于组织问题和准备提问，不能替代具备资质的专业意见。
