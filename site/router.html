推荐组合

CoT + Critic 验证链

深度推理链（Chain of Thought）+ 批判者角色自我验证，用于高风险/高精度推理任务

  1. 问题分解（Decompose）输入：原始复杂问题输出：子问题树：{子问题列表, 依赖关系, 求解顺序}停止：所有子问题合起来完整覆盖原问题
  2. 逐步推理（Chain-of-Thought）输入：子问题 + 已知信息输出：推理链：每步格式 = {规则, 应用, 结论, 置信度, 依赖假设}停止：所有子问题有推理结论
  3. 批判审查（Critic）输入：Phase 2 的完整推理链输出：批判报告：{发现的问题列表, 每个问题的严重程度, 修复建议}停止：没有严重问题 OR 所有严重问题已标注
  4. 修正推理（Revise）输入：Phase 2 推理链 + Phase 3 批判报告输出：修正后的推理链（标注哪些步骤被修改）停止：所有严重问题已被修复
  5. 验证综合（Verify & Synthesize）输入：修正后的推理链输出：最终结论：{核心答案, 关键假设, 整体置信度, 适用边界, 无效场景}停止：输出完整

  2. 分支展开（Branch）输入：问题规范输出：分支树：每个分支 = {方向名称, 核心假设, 预期结果, 需要验证的条件}停止：覆盖了足够多样的方向（不同策略原理）
  3. 分支评估（Evaluate）输入：所有分支输出：评估矩阵：每个分支有多维评分 + 综合得分 + 优先推进的1-2个分支停止：产出可供下一阶段使用的结果
  4. 深度展开（Deepen）输入：排名前2的分支输出：每条路径的完整推演：{步骤序列, 关键决策点, 可能的障碍, 最终状态}停止：产出可供下一阶段使用的结果
  5. 路径选择（Select）输入：所有深度推演结果输出：最终决策：{选择的路径, 选择理由, 触发重选的条件, 风险缓解措施}停止：产出可供下一阶段使用的结果

推荐组合

ReAct 推理行动链

Reason → Act → Observe 循环，用于需要与外部工具/环境交互的复杂任务

  1. 意图澄清（Intent Clarification）输入：用户的原始任务描述输出：结构化任务规范：{目标, 成功标准, 约束, 已知信息}停止：任务目标和成功标准已被明确确认
  2. 推理（Reason）输入：来自 Phase 1 的结构化任务规范输出：行动计划：{行动序列, 每步预期输出, 判断标准}停止：行动计划覆盖了所有必要步骤
  3. 行动（Act）输入：来自 Phase 2 的行动计划，执行第 N 步输出：行动结果：{原始输出, 工具/方法, 执行状态}停止：行动已执行，有明确的输出（成功/失败/需要追问）
  4. 观察（Observe）输入：来自 Phase 3 的行动结果输出：观察报告：{匹配度, 新发现, 计划修正（如需）, 是否继续循环}停止：任务完成 OR 达到最大迭代次数 OR 无法继续
  5. 综合输出（Synthesize）输入：所有历史 Reason-Act-Observe 记录输出：最终结论：{核心答案, 推理过程, 置信度, 局限说明}停止：用户目标已被满足
