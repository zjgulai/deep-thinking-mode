### 2026-08-09 设计纠偏

V1 的十三张人物图在技术、性能和发布层面通过，但在人物审美层面不合格：面孔、发型、姿态、
服装轮廓和材质高度同质；皮肤、头发和衣物被统一渲染成暖白纸浆、石膏或陶俑，人物缺乏真实
生命感与时代差异。这个问题不能靠换章节色、增加首饰或继续微调同一母版解决。

V2 冻结以下决定：

1. 人物与背景不必同色，也不得同材同明度；系列统一来自版式、镜头、光线和纸艺舞台语法。
2. 人物使用自然肤色、黑褐发丝和可辨识丝、麻、锦、甲片等衣料；纸雕仅用于环境、框景、器物
   抽象层和章节知识隐喻。
3. 人物可以使用唐彩、矿物色和各时代可信的流行色，但每张限制在 4–6 个颜色角色，不套全图
   黄褐滤镜，不把“克制”等同于灰白。
4. 十三位导师统一采用 20–35 岁、明确成年的“意气风发青年导师”策展形象；这是跨时空品牌
   演绎，不声称对应其代表成就发生时的真实年龄。人物仍必须在脸型、发髻轮廓、服装骨架、
   动作方向、注视对象和场景中可辨，不再接受“换器物但人物不变”。
5. 先生成班昭、武则天、秦良玉三位跨度样片，每人两种候选方向，共六张；三位全部通过后才
   生产其余十位，旧图在用户批准新图前保持在线且可回滚。

### 2026-08-09 第二次设计纠偏：从“工作照”转为“人物志美照”

V2 青年化解决了年龄和石像材质，却仍把“导师”误解为“必须正在授课或工作”，导致三人都在
桌前、案前或整队，且暗红、墨绿、铁黑占据大面积。用户明确否决这种低饱和工作照路线。

V3 冻结以下增量规则：

1. 导师身份不等于工作动作。人物可以处于生活美照、宫廷华照、旅途纪行或战场英姿；知识
   身份由人物、时代器物、章节文案和页面结构共同建立，不要求每张图都出现书案、奏表或笔。
2. 十三章场景按 `生活/诗意`、`宫廷/仪典`、`行动/天地` 三个互斥主类型分配；每张只能有一个
   主类型，防止所有人物重复伏案，也防止所有人物都变成花园写真。
3. 图片使用 5–7 个清晰颜色角色，至少三个中高彩度角色在 320px 缩略图仍可辨；整体必须高明度、
   空气通透，不以暗红、墨绿、铁黑或黄褐滤镜覆盖全图。史实复核只收紧衣冠骨架，不负责把
   鲜艳颜色重新压灰。
4. 新增两套候选风格：A `华彩写实人物志`，强调真实肤质、真实丝绸和电影感；B `东方仙韵工笔`，
   强调矿物色、飘带、风与工笔线，但不使用翅膀、法术、漂浮身体或纸塑人物。
5. 参考公开案例时只萃取可描述的方法。可保留“真实人物为主、朝代器物参与构图、2–4 段断续
   轮廓线跟随姿态、分朝代色彩人格”；不得复制其人物、脸、服装、姿势、构图、标题或暗色调，
   也不得把权利不明的参考图作为生成输入。
6. 图片内不生成主标题与正文。参考案例中的 Typography 改由 HTML/CSS 实现；断续线条可作为
   图片内点缀或页面 SVG 装饰，但不能完整描边人物，也不能影响正文对比度。

### 2026-08-09 第三次设计收敛：从“单条提示词”升级为“东方人物视觉工作室”

用户提供的内部 V4.1 东方人物摄影工作室母提示词与 12 张案例，证明“人物身份档案、系列视觉锁、
造型/镜头/灯光分阶段策划、提示词编译、评分与失败恢复”比不断堆叠形容词更可靠。其方法可以
迁移，但成片模板不能照搬：案例共包含 37 个画面，人物主体大量复用相近脸型、高后髻、低头
侧视和桌边静态动作；图片内生成文字还出现不可验证、不可访问和朝代标注不一致的风险。这正是
本项目此前“同脸、同髻、工作照”问题的另一种精致版本。

项目由此采用 `东方华彩人物志 × 纸上山河` 的统一方向，并将 C 混合方案细化为六个相互独立的
生产合同：

1. `MENTOR_IDENTITY_PROFILE`：每位导师独立记录脸部骨架、五官比例、自然不对称、肤色与质感、
   体态、年龄感、眼神、发际线和不可与谁相似；不依赖不存在的真实肖像，也不声称复原容貌。
2. `ERA_EVIDENCE_PACK`：发式、服装轮廓、面料、饰物、器物和建筑逐项记录
   `confirmed/inferred/adapted`；美学加工不能覆盖证据状态。
3. `CHAPTER_SCENE_BRIEF`：先定义生活/游赏、宫廷/仪典或行动/天地中的一个叙事瞬间，再定义
   动作、视线、风向、主器物与章节隐喻；不得由生成器自行把所有人物送回书案或茶席。
4. `CINEMATOGRAPHY_PROFILE`：景别、焦段感、机位、主光、轮廓光、景深、人物占比、留白和三个
   派生画幅安全区均在生成前冻结。
5. `SERIES_DNA`：只锁定真实人物材质、东方编辑摄影质感、断续线稿、纸艺远景、明亮用色和
   HTML/CSS 排版秩序；脸、发髻、衣冠、动作、器物和空间轴线必须成为章节变量。
6. `ASSET_QA_AND_RECOVERY`：按人物、时代、叙事、色彩、摄影、网页裁切、资产来源分别评分；
   失败时只回退到对应合同修复，不用“再生成一张看看”掩盖根因。

#### 东方美学的四层优先级

东方美学不以汉字、香炉、玉璧、圆扇和高髻出现的数量计分，而按下列顺序建立：

1. **神与势**：人物的眼神、重心、动作未完成感、衣袖和风的方向，先让人物活起来。
2. **形与制**：朝代可信的发式剪影、领型、腰线、袖量、裙形、甲胄和建筑比例。
3. **材与色**：自然皮肤、黑褐发丝、丝麻锦甲的真实受光，以及有时代依据的华彩色。
4. **器与纹**：团扇、玉器、香具、花木、线稿和纸艺只能加强叙事，不能替代前三层。

任一作品若前三层不成立，即使摆满传统符号也不视为东方美学合格。

#### 色彩从“禁过饱和”改为“面积受控的华彩”

内部参考的“禁过度饱和”不能被解释成全图降灰。本项目采用面积与层级控制：

- 55–70% 为高明度空气、纸面、天空或建筑留白，不套黄褐滤镜。
- 20–30% 为 2–3 个时代主色，允许石榴红、孔雀蓝、松石绿、鹅黄、胭脂、黛紫等中高彩度色。
- 5–10% 为金属、花蕊、披风、兵器穗或首饰等高彩度焦点，不扩散成满屏荧光色。
- 5–10% 为头发、眼睛、墨线和必要深部结构，用于建立清晰度而不是制造暗沉气氛。

人物服色不必与页面背景同色；页面从图片中提取一个章节强调色，但正文、状态色和可访问性
对比度仍由 CSS 语义令牌控制。

#### 摄影感与仙韵的混合边界

- 人脸、皮肤、手、马匹和关键器物采用华彩写实摄影的物理可信度。
- 衣袖、披帛、花木、云气、远山和知识隐喻采用工笔线、矿物色与分层纸艺的东方气韵。
- 断续线稿每张 2–4 段，只短暂贴合一次发梢、袖缘、兵器或建筑走势后进入留白；不得描完整
  人体轮廓，也不得成为发光特效。
- 图片内禁止任何标题、说明、朝代英文、印章字和伪书法。所有文字由网页排版，图片只保留
  纯视觉叙事。
- 单人身份锚点批准后再以编辑方式派生卡片、桌面 Hero 与移动 Hero，避免三个画幅生成三张脸。

#### 跨人物防撞锁

V4 在每个 `MENTOR_IDENTITY_PROFILE` 外增加 `SERIES_IDENTITY_COLLISION_MATRIX`。任意两位不得同时
复用以下七项中的五项：脸型比例、眉眼走向、鼻唇结构、发髻剪影、体态重心、注视方向、主动作。
同朝人物额外比较领型、袖量、腰线和首饰密度。生成前写入“不得接近的已批准人物”，生成后用
无标签 contact sheet、脸部裁切和发髻剪影三次复核；一旦撞脸，回退身份档案，不以换背景修补。

## 2. 核心设计结论

产品不是“古风美女网站”，而是由历史女性精神身份引导的知识工作台。人物之美来自才学、
判断、行动与时代处境；视觉不得把人物降格为装饰性容貌标签。

V2 统一视觉公式为：

```text
历史女性的精神身份与生活、宫廷或行动瞬间
  + 有时代依据的彩绘人物、发髻与衣冠
  + 章节知识的立体纸艺空间隐喻
  + 纪念碑式留白与品牌秩序
```

“唐风”在本项目中表示开阔、庄重、从容、重秩序的品牌气象，不表示十三位人物统一穿唐代
服装。人物服饰、发髻、器物和空间语境必须服从各自朝代；统一的是构图秩序、单一动机光源、
纸艺舞台和品牌节奏，不是把人物统一做成同一种纸、石膏或陶土。

章节页采用 `80% 固定知识工作台 + 20% 章节专属策展身份`：十三章可以一眼区分，但用户的
阅读路径、搜索、模型卡、状态语义和键盘操作不因章节改变。

## 3. 品牌人格与视觉原则

### 3.1 品牌人格

- 大气：留白、稳定轴线和清楚的内容主次，而不是堆满宫殿、花纹和金光。
- 精致：纸张厚度、纤维、裁切边、层间薄影和器物考据，而不是更多装饰。
- 理性：章节意象必须解释知识方法，不能只是常见古风符号。
- 温度：导师以正在观察、整理、推演、书写或行动的姿态出现，不是冷漠塑像。
- 克制：不使用网红脸、幼态化、媚态、过度露肤、影楼妆造或宫斗海报。
- 诚实：所有人物图都是艺术化演绎，不声称复原真实容貌，不伪造名言。

### 3.2 三种艺术语言的职责

| 艺术语言 | 唯一职责 | 不负责 |
|---|---|---|
| 纪念碑式构图 | 秩序、庄重、尺度和留白 | 服饰考据、交互状态 |
| 浅浮雕 | 环境基座、建筑轮廓和历史重量 | 人物皮肤、头发、衣物 |
| 立体剪纸 | 前中后景、器物关系和知识隐喻 | 人物身体材质、满幅花海或梦幻氛围 |
| 彩绘人物 | 面孔、发丝、衣冠、动作和时代生命感 | 替代史实证据或制造影视角色 |

### 3.3 材质与色彩边界

| 对象 | 必须使用 | 禁止使用 |
|---|---|---|
| 皮肤 | 自然温润肤色、轻微真实纹理、年龄痕迹、柔和明暗 | 纸浆、石膏、陶俑、石像、塑料磨皮、统一惨白 |
| 头发 | 墨黑至深褐发丝、可见发束和少量自然碎发 | 暖白纸发、整块石头、十三人同一高髻 |
| 衣物 | 可辨识丝、麻、绢、锦、布面甲或札甲；有层次和受力 | 同色纸袍、廉价 cosplay、跨朝代拼装、影视龙袍凤冠 |
| 首饰与器物 | 克制的金属、木、漆、竹、陶或纺织质感 | 全部刷成暖白、无依据的奢华堆砌 |
| 环境与知识隐喻 | 3–6 层纸雕、剪纸、浅浮雕、纤维与接触薄影 | 把人物一并材质化、塑料 3D、树脂玩具 |

人物服色是章节识别的主要视觉变量，可以比页面背景更鲜明；背景保持高明度、低彩度和充足
留白。人物色彩建议占图像视觉重量的 20%–30%，环境纸色约 60%–70%，金、墨或反差定位色
不超过 10%。暗色模式只改变网页承托框，不反相、不滤色、不改人物肤色与衣色。

### 3.4 视觉密度

- 页面只允许章节 Hero 为高密度装饰区。
- 主题区和章节翻页为中低密度。
- 面包屑、搜索工具栏和模型列表必须低密度。
- 同一页面只出现一次完整导师图；微型章节签名最多出现六次。
- 单个 Hero 只用一个主纹样和最多两个辅助器物，视觉纸层控制在 3–6 层。

## 6. 装饰 MECE 系统

每项装饰必须且只能有一个首要职责：

1. 人物身份：回答“由谁引导”，只含导师肖像、姓名、朝代和身份。
2. 知识隐喻：回答“本章如何思考”，只含与方法直接相关的器物和空间。
3. 章节签名：回答“当前是哪一章”，只含章节编号、强调色和微型主纹样。
4. 结构秩序：回答“内容如何分组”，只含纸缘、细线、留白、框架与层级。
5. 氛围材质：回答“这是什么审美世界”，只含纸纤维、浅浮雕、低饱和色差和统一光线。
6. 状态反馈不属于装饰：焦点、错误、警告、选中、复制和筛选结果使用全站功能组件。

同一图形不能同时充当章节标识、风险警告和按钮。章节色不能覆盖 Warning、Danger、Success、
`needs_review` 或 `needs_medical_review` 等状态语义。

## 7. 章节页六区

### 7.1 入卷门槛：面包屑

- 固定：首页 / Ch.XX 章节名，语义为 `nav`。
- 变量：当前章标题前一个 14–18px 微型签名和一条短纸页切口线。
- 禁止：人物头像、背景插画、复杂花边。
- 移动端：自然换行；打印时隐藏。

### 7.2 开卷主场：章节 Hero

- 全页唯一完整导师肖像和完整纸雕知识剧场。
- DOM 先出现章节编号、H1、简介、导师身份和策展导语，再出现 `figure`。
- 图像内不得生成标题、印章字、Logo 或水印；文字不覆盖脸部。
- 导师图是信息内容，必须有 `alt`、固定宽高、可见 caption 和艺术化演绎声明。
- 桌面文字与人物约 `56:44`；移动端单列，人物置于简介之后。
- 打印隐藏高墨量场景，只保留导师姓名、朝代、身份和演绎声明。

### 7.3 本章脉络：主题区

- 使用有标题的语义列表，视觉像卷册目录签，不是标签云。
- 主纹样只在区标题旁出现一次；每个主题使用编号和细纸缘。
- 如果主题不可筛选，不伪装为按钮；如果成为筛选器，必须使用真实 `button`、
  `aria-pressed` 和清除入口。
- 打印转为紧凑文字列表并去除底色。

### 7.4 检索案台：模型工具栏

- 固定“本章模型”、排序说明、搜索框和可见结果数。
- 只在标题旁放一次短横式纸雕分隔符；搜索框保持全站统一功能样式。
- 搜索框必须有 label，结果状态使用节制的 `aria-live="polite"`。
- 移动端纵向排列；打印隐藏输入框，保留模型总数。

### 7.5 知识陈列：模型列表

- 模型卡结构、内容、Agent 角色和风险状态全站固定。
- 只允许 2px 章节色标、极小微纹样和最多 2px Hover 抬升。
- 不为每张模型卡生成图片，不重复导师头像，不使用卷轴或镂空重边框。
- 打印单列、无阴影，并用 `break-inside: avoid` 保护卡片。

### 7.6 合卷转场：章节翻页

- 上一章和下一章各显示目标章节编号、名称、强调色和微型签名。
- 不加载相邻导师图片；方向同时由文字和箭头表达。
- 第一章或末章不输出无意义的空交互元素。
- 移动端纵向排列；低动效关闭箭头位移；打印隐藏。

## 8. 模型详情页继承边界

章节页是策展展厅，模型详情页是推理工作台。2789 个模型详情页只继承：

- 章节强调色。
- 一个 12–16px 微型章节签名。
- 面包屑中的章节名称和导师文本入口。
- Hero 分隔线、章节 kicker 或协议圆章的轻微章节化。

模型详情页不得继承：

- 完整导师肖像和纸雕知识剧场。
- 大面积章节背景纹样。
- 历史人物导语或未经核验的引语。
- 为模型单独生成的装饰图片。
- 对风险、证据和 Agent 状态色的覆盖。

这样既避免 2789 页的性能和视觉重复，也避免让用户误以为历史人物是现代模型作者。

## 9. 图像资产规范

### 9.1 角色圣经

每位导师先建立唯一角色设定，至少包含：

- 姓名、朝代、身份、可核验史实和争议点。
- 年龄阶段、体态、脸型、眉眼、鼻、唇、肤质、年龄痕迹和自然不对称等面部锚点。
- 发缝、额发、发髻高度与轮廓、编束方式、发饰数量和禁止复用的发型剪影。
- 内外衣层、领型、袖型、腰线、下装、面料、纹样、甲胄结构和每项资料依据。
- 唯一动作、非主动作手臂的自然状态、注视对象、微表情和动作造成的衣料受力。
- 人物主色、环境纸色、深色焦点和 4–6 个颜色角色；肤色不随章节色染色。
- 标准正面、四分之三侧面、全身比例、卡片安全区和 Hero 安全区。
- 章节主色、主纹样、辅助器物和禁止元素。

上述字段必须先写入结构化角色圣经再生成图片。不得只保存姓名、朝代和一句“古风美女”后让
模型自行补全发型、服装和动作。

后续卡片图与 Hero 必须基于已批准锚点派生，不重新随机生成另一张脸。

背景承载有语义的人物图。V4 最终人物原图是纵向叙事构图，章节 Hero 因此采用 4:5 纸框而非
破坏性强裁 16:9；桌面通过图文并置建立横向层次，移动端保持同一身份与完整器物。

### 9.3 可见声明

统一使用：

> AI 艺术化演绎：依据人物时代的服饰、器物与文化资料创作，非真实肖像。

章节首次出现导师时补充：`统一采用20–35岁青年导师策展形象，不对应其代表事件发生时的真实年龄。`

`alt` 描述人物身份、动作和关键知识场景，不使用“美女”“绝美容颜”等物化表达，也不重复
页面已经可见的长说明。

## 10. V2 图像提示词协议

V1 的“人物、服装、器物和环境由统一高级纸材构成”已停用。它是皮肤石膏化、头发纸块化、
衣装同质化的直接原因。V2 采用 Prompt as Code：按固定顺序填写原子字段，由结构化数据编译
为提示词；不再为十三章复制一篇泛化风格散文。

### 10.1 协议字段

```json
{
  "output_contract": "用途、比例、尺寸、人物占比、标题与裁切安全区",
  "story_event": "一句话说明正在发生的教学瞬间",
  "identity": "姓名、朝代、成年年龄段、社会身份、教学人格",
  "historical_evidence": "发髻、衣冠、器物的来源ID及 confirmed/inferred/adapted",
  "face_bible": "脸型、眉眼鼻唇、肤质、年龄痕迹、自然不对称、禁用脸型",
  "hair_bible": "发缝、额发、髻高、轮廓、编束、发饰、禁用剪影",
  "wardrobe_bible": "衣层、领袖腰线、下装、面料、纹样、配色、禁用错代元素",
  "performance": "一个主动作、一个注视对象、一个微表情、衣袖与重心的物理结果",

  "material_boundary": "自然人物材质与纸艺环境的明确分界",
  "palette_zones": "页面中性、环境纸色、人物服色、金墨焦点与各自占比",

```

提示顺序固定为：输出契约 → 叙事瞬间 → 人物身份 → 史实锚点 → 面孔与发髻 → 衣冠 →
动作与注视 → 构图 → 材质边界 → 分区配色 → 单一光源 → 纸艺环境 → 负面约束。每轮迭代只
改一个主要变量并记录结果，不在失败图上同时叠加多组互相冲突的形容词。

### 10.2 推荐方向 A：彩绘人物 × 素纸舞台

这是十三章主视觉的默认方向：高端历史编辑人像与克制工笔设色相结合，人物五官、发丝、
衣料和动作生动可信；背景、框景、建筑轮廓、章节器物和知识隐喻采用高明度立体剪纸与浅浮雕。
人物服色可使用石榴红、青绿、靛蓝、赭黄、胭脂、金等时代可信色，但不做影视写真、廉价
cosplay 或通体彩灯。该方向在首页小卡、移动端和十三人差异化上最稳定。

### 10.3 候选方向 B：工笔重彩人物 × 彩色剪纸剧场

人物使用更明显的工笔线性和矿物设色，环境纸层也保留独立色块，整体更华美、更接近“唐彩”。
它适合武则天、徐惠、上官婉儿等部分章节或章节开卷，但更容易变成旅游海报、宫斗剧或满幅
装饰。因此只作为三人样片对照，不直接成为十三章统一默认。

## 11. 无障碍、响应式、低动效与打印

- 正文对比度至少 4.5:1，大文本和必要图形至少 3:1。
- 章节身份由编号、名称、导师和纹样共同表达，不只靠颜色。
- 装饰微纹样使用 `aria-hidden="true"` 或伪元素；人物图不得设为空 `alt`。
- 页面保持一个 H1、正确标题层级、“跳至正文”、可见焦点和 44px 触控目标。
- 320 CSS px 不得产生页面级横向滚动。
- `prefers-reduced-motion: reduce` 下显式关闭 transform、平滑滚动和非必要 transition；
  不能只把动画时间压缩为瞬时跳动。
- 不使用视差、循环粒子、Canvas、WebGL、背景位移动画或跟随指针的导师。
- 打印隐藏顶栏操作、搜索输入、章节翻页和高墨量图景，保留章节标题、导师身份、模型摘要、
  来源、风险、演绎声明和 URL。
- 深色模式使用独立章节 token，不对图片做简单反色，也不让章节色削弱风险状态。

## 12. 性能与确定性预算

- 新增视觉系统原则上不增加客户端 JavaScript。
- 共享章节主题 CSS 新增不超过 10 KiB gzip。
- 单章微纹样 SVG 不超过 3 KiB。
- Hero AVIF：桌面不超过 180 KiB，移动不超过 100 KiB；WebP fallback 不超过 260 KiB。
- 首页十三张缩略图合计目标不超过 650 KiB，并按视口延迟加载非首屏图。
- 单章新增装饰 DOM 不超过 30 个节点；模型卡不增加逐卡图片请求。
- 不预加载上一章或下一章导师图。
- 移动中端设备目标：LCP ≤ 2.5s、CLS < 0.1、INP < 200ms。
- 同一公开输入必须生成路径集合与 bytes 相同的 `site/` 和 `docs/`；图片优化工具、版本和参数
  必须锁定，禁止把生成时间或随机 ID 写入产物。
- 全部资源来自站点本地，不增加 CDN、远程字体、远程图像、XHR、fetch 或 analytics。

## 14. V2 实施前样片门

批量生产前只制作三位跨度最大的导师：

1. 班昭：验证学者型、典籍、纸本和总导师气质。
2. 武则天：验证权力型人物能否庄重而不影视化。
3. 秦良玉：验证武将型人物能否与精致知识工作台统一。

V3 每位先生成两张角色母版候选：

- A：`华彩写实人物志`：真实肤质、真实丝绸、鲜明时代色与电影感生活/宫廷/行动场景。
- B：`东方仙韵工笔`：真实人物材质、工笔线、矿物色、飘带和分层彩纸远景。

首轮共六张，不直接生成卡片、桌面 Hero 和移动 Hero 三套独立人物。每位先批准一个角色锚点，

### 14.1 硬性否决项

出现任一项即失败，不以总分抵消：

- 皮肤、头发或衣物读作石膏、石头、陶俑、兵马俑、纸浆、树脂或蜡像。
- 与另一导师明显同脸，或无史实理由地复用同一发髻剪影和服装骨架。
- generic hanfu、错朝代衣冠、现代妆造、影视龙袍凤冠或廉价 cosplay。
- 无动作关系的正面僵站、所有人看镜头、所有人重复工作照、手与器物不接触或表情无焦点。
- 全图暗红、墨绿、铁黑、黄褐或灰米色占主导；320px 缩略图无法分辨至少三个独立彩色角色。
- 幼态、未成年、性化、额外肢体、畸形手、可读文字、Logo、印章字或水印。
- 缺史实来源状态、参考权利记录、提示词 hash、模型版本或最终资产 hash。

### 14.2 百分制评审

| 维度 | 分值 | 通过证据 |
|---|---:|---|
| 史实与时代边界 | 25 | 发髻、衣冠、器物逐项有来源状态，无跨朝代混搭 |
| 面孔与生命感 | 20 | 明确为20–35岁年轻成人而非幼态；五官锚点、眼神、微表情和自然不对称成立 |
| 发髻与服装差异 | 20 | 与其余导师的轮廓可辨，衣层、面料和受力可信 |
| 叙事动作与章节身份 | 15 | 一个生活、宫廷或行动瞬间，一个注视对象与时代器物形成因果关系 |
| 色彩与材质 | 10 | 高明度且至少三个彩色角色可辨，皮肤/发丝/衣料与纸艺环境明确分离 |
